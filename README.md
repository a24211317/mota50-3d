# 魔塔五十层 · 第一人称 3D 版

带上剑和盾，走进一座五十层的魔塔。这个浏览器小游戏把经典《魔塔50层》的地图、钥匙、机关和剧情搬进了第一人称地牢。战斗依然按攻防数值结算。先开哪扇门、先拿哪颗宝石，往往比先打哪只怪更重要。

## 开始冒险

下载仓库里的 `index.html`，用桌面版 Google Chrome 打开，点击「开始冒险」即可游玩。地图、美术和运行代码都在这一个文件里，支持离线游玩，无需安装 Flash 或启动服务器。

## 操作

| 操作 | 按键 |
| --- | --- |
| 前后左右移动 | 按住 W、A、S、D |
| 环顾四周 | 移动鼠标 |
| 拾取、战斗、开门、上下楼或与人物交谈 | 靠近并看向目标，按 F |
| 查看楼层地图、属性、装备和道具 | Tab |
| 暂停、调整音量和鼠标灵敏度、返回主菜单 | Esc |

## 存档

游戏会在本机浏览器里自动保存进度。下次打开同一个文件，点击「继续冒险」即可接着玩。换设备、移动游戏文件或清理浏览器数据前，可以在暂停菜单里选择「导出备份」，再从主菜单选择「导入存档」恢复进度。

本作是对经典《魔塔50层》的非官方第一人称改编，3D 场景使用 Three.js 渲染。

本项目使用 GPT-6 Astra 开发。后续直接修改 `index.html`，保存后刷新浏览器即可试玩。
